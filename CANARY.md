# Lifecycle Automation Canary

This repository contains synthetic projects and GitHub records used only to
verify the `anzihenry/software-engineering` lifecycle automation on GitHub.

- No production code, credentials, personal data, incident data, or user data.
- Canary pull requests are closed rather than merged and remain as evidence.
- Repository settings are changed only by an explicitly confirmed bootstrap.
- The repository is retained for repeatable validation and is not deleted by automation.
